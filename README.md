# Portfólio React

Protótipo de portfólio pessoal desenvolvido com componentes React. Reúne seções de apresentação, biografia e links sociais.

## Stack
- React
- JavaScript
- HTML e CSS

## Como executar
O repositório não declara um script npm de execução. Consulte `index.html`, `index.js` e `webpack.config.js` para a configuração do protótipo e execute-o em um ambiente React compatível.
